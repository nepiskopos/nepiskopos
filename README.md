## 🧠 Open-Source Projects

- 📈 [**Governed Analyst Agent**](https://github.com/nepiskopos/governed-analyst-agent): natural-language analyst agent over a multi-tenant ClickHouse warehouse, with a semantic layer, database-enforced tenant isolation and guarded SQL. Answered 45 of 46 gold-set questions correctly with no critical failures, at $0.01 per correct answer. Also includes a churn model with out-of-time validation.
- 🕵️ [**API Hunting Agent**](https://github.com/nepiskopos/api-hunting-agent): autonomous reason–act–observe LLM agent that tests OWASP crAPI for information-disclosure flaws. Hardened over 25 review passes against the live target, with 39 bugs fixed and 322 tests.
- 💬 [**Mackie**](https://github.com/nepiskopos/conversational-social-media-agent): LangGraph agent that plans and drafts on-brand social media posts for nonprofits, learns from feedback and isolates each organization's data with PostgreSQL row-level security. Runs on any LiteLLM model, with 1,000+ tests and 95% branch coverage in CI.
- 🔐 [**LangGraph PII Detector**](https://github.com/nepiskopos/langgraph-pii-detector): PII detection agent with LangGraph and Azure OpenAI GPT-4o. A simplified public version of a detector built at IBM for the National Bank of Greece.
- 📄 [**Document Summarization AI**](https://github.com/nepiskopos/langgraph-document-summarization): document summarization agent with LangGraph and Azure OpenAI GPT-4o, using parallel graph execution.
- 🧪 [**LLM Fine-tuning with LoRA**](https://github.com/nepiskopos/llm-finetuning-with-lora): end-to-end fine-tuning of a Qwen3-0.6B chat assistant with LoRA and 4-bit quantization, served by FastAPI in CPU and GPU Docker containers.
- 🛰️ [**Federated Intrusion Detection (IEC 104)**](https://github.com/nepiskopos/simple_ids_with_flwr_iec104) and [**(TensorFlow Federated)**](https://github.com/nepiskopos/simple_ids_with_tff): intrusion detection for a power-grid control protocol (IEC 60870-5-104), trained with federated learning.
- ⚙️ [**Open WebUI Enhancements**](https://github.com/nepiskopos/open-webui-enhancements): custom tools, functions and pipeline extensions for Open WebUI, for prompt engineering, RAG and experimental LLM workflows.
